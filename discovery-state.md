# Discovery State — Dydat UX Redesign

## Fase corrente: 3 completata → pronto per Fase 4 (Concept Document)

## Decisioni prese:
- D1: UI unica allegra-non-infantile + tutor adattivo (calibrato da onboarding)
- D2: Tono serio/caldo/leggero a seconda del contesto
- D3: Sessione ibrida (feed + esercizi/visualizzazioni che escono dal feed)
- D3b: Tutor con capacità visive generative (tool-use → widget nativi → WebView)
- D4: Tre fasi di implementazione (A esperienza base, B visual nativi, C motore generativo)
- D5: Visualizzazioni generative come feature premium (idea, non decisione finale)
- D6: Home dedicata come punto di ingresso
- D6b: Quaderno dello studente — contenuti accessibili fuori dalla sessione
- D6c: Percorsi generati da domande curiose (visione futura)
- D6d: Quaderno organizzato per nodo (concetto), non per percorso
- D7: Ritorno dopo assenza: gentile + FSRS adattivo
- D8: 3 tab (Home, I miei studi, Profilo) + modalità Studio immersiva
- D9: Mascotte = tutor reso visibile
- D10: Gamification celebra comprensione e coraggio, mai punisce. Eccezione: onesta sul ripasso FSRS
- D11: Onboarding con momento wow iniziale → domande rapide → conversazione tutor → percorso → registrazione
- D12: Transizione in sessione con animazione mascotte (breve, espressiva)
- D13: Promozione nel canvas, mascotte celebra, studente sceglie se continuare
- D14: Chiusura sessione: recap narrativo del tutor + numeri sotto
- D15: Percorso con vista adattiva (lineare default, grafo completo con zoom out)
- D16: Profilo: numeri compatti in alto, storia e achievement sotto
- D17: Notifiche push strutturate e presenti (ripasso FSRS, continuità, celebrazione)
- D18: Sessione a obiettivo + tutor suggerisce pause + notifica se esci prima
- D19: Sistema audio completo (micro-suoni + musica opzionale + configurabile)

## Gap aperti:
- Nessun gap critico rimasto
- Da definire in fase di implementazione: dettagli UI, animazioni specifiche, domanda wow onboarding, tipi concreti di achievement, set iniziale di visualizzazioni native
