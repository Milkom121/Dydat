# Test Manuali — Dydat

> Checklist di test da eseguire sull'emulatore/device. Spuntare quando verificati.

---

## Fase 5 — Ripasso Intelligente

- [ ] La schermata principale mostra la sezione "Da ripassare" (se ci sono argomenti da ripassare)
- [ ] Gli argomenti nel percorso mostrano un bollino arancione se da ripassare
- [ ] Il bottone "Vai" nella sezione ripasso avvia una sessione di ripasso
- [ ] La sessione di ripasso propone esercizi sull'argomento corretto
- [ ] Dopo una sessione di studio normale, tornando alla home compaiono nodi da ripassare

### Prerequisiti
- Serve almeno una sessione di studio completata con esercizi superati per generare nodi da ripassare
- Account dev: premere "Login rapido dev" nella schermata di login
